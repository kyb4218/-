# 프로젝트 이름: 대구광역시 버스 정보 시스템 (Frontend)

## 개요
본 프로젝트는 **대구광역시 버스 정보 시스템**의 프론트엔드 영역으로,  
백엔드 REST API 서버와 연동하여 **실시간 버스 정보, 사용자 서비스, 버스회사 관리자 및 시스템 관리자 기능**을 웹 UI로 제공하는 프로젝트입니다.

Vue 3 기반 SPA 구조로 개발되었으며,  
사용자 권한(Role)에 따라 **일반 사용자 / 버스회사 관리자 / 시스템 관리자** 화면을 분리하여 제공합니다.

---

## 🎯 주요 기능

대구광역시 버스 시스템 프론트엔드는  
백엔드에서 제공하는 기능을 **역할(Role) 기반 UI**로 시각화하여 제공합니다.

---

### 👤 일반 사용자 기능 (일반회원)

- 버스 노선 및 정류장 검색 / 조회
- 실시간 버스 위치 지도 시각화
- 버스 요금, 운행 시간표, 회사 정보 조회
- 분실물 조회 및 분실물 신고 등록
- Q&A 작성 및 답변 확인
- 즐겨찾기(노선 / 정류장) 관리

#### 🧾 마이페이지
- 회원 정보 수정 및 탈퇴
- 알림 조회
- API 키 발급 상태 및 승인 여부 확인

---

### 🚌 버스회사 관리자 기능 (BUS)

- 소속 버스회사 기준 **습득물 등록 / 수정 / 삭제**
- 습득물 상태 관리 (보관중 / 수령완료)
- 일반회원 분실물 목록 조회 (열람 전용)
- 버스회사 운영을 위한 전용 관리 화면 제공
- 시스템 관리자 기능과 분리된 **BUS 전용 메뉴 구성**

---

### 🛠 시스템 관리자 기능 (ADMIN)

#### 🗂 게시글 관리
- 공지사항 등록 / 수정 / 삭제
- 팝업 공지 노출 설정
- 광고 및 광고회사 관리

#### 🎒 분실 / 습득물 관리
- 전체 분실물 / 습득물 관리
- 습득물 기준 분실물 매칭 처리
- 상태 자동 전환 처리

#### 🚌 버스 데이터 관리
- 버스 노선 등록 / 수정 / 삭제
- 정류장 등록 / 수정 / 삭제
- 노선별 운행 시간표 관리

#### ⚙ 시스템 관리
- API 키 발급 / 승인 / 비활성화 관리
- 시스템 로그 및 통계 대시보드 연동

---

### 🔐 인증 및 권한

- Kakao, Google OAuth2 로그인 기반 UI 처리
- 사용자 권한(Role)에 따라  
  **관리자 / 버스회사 관리자 / 일반회원** 구분
- 메뉴 및 화면 접근 제어

---

## 💡 정리 포인트

- 프론트엔드는 **USER / BUS / ADMIN 역할 구조를 명확히 분리**하여 UI를 구성했습니다.
- 실제 서비스 운영 환경을 고려하여  
  관리자와 버스회사 관리자의 기능을 분리 설계했습니다.
- 백엔드 권한 구조와 **1:1로 대응되는 화면 구성**입니다.

---

## 🛠 기술 스택
- **Frontend**: Vue 3, Vite
- **상태 관리**: Pinia
- **라우팅**: Vue Router
- **UI**: Bootstrap, Custom Components
- **지도**: OPENROUTESERVICE API
- **API 통신**: Axios
- **인증 처리**: JWT 기반 인증 연동
